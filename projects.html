DATABASE SYSTEMS · SQL

Flight Management System

Analyzed an existing flight database containing airline, aircraft, airport, and flight information. Developed SQL queries to answer business case questions and interpreted results to identify operational patterns and potential business opportunities.

Project focus

  • Processed relational flight data using PostgreSQL.
  • Used SELECT, FROM, JOIN, LEFT JOIN, GROUP BY, and ORDER BY.
  • Translated query results into insights related to operational efficiency, market reach, and strategic planning.
PostgreSQLSQLData AnalysisBusiness Insight

UI/UX DESIGN · DIGITAL SERVICE INNOVATION

FIX NOW

A digital platform concept that connects customers with local technicians for household repair services. The concept responds to challenges such as unclear service prices, slow responses, limited trust, and technicians’ difficulty finding consistent customers.

Project focus

  • Designed a simpler and more transparent service booking experience.
  • Considered technician verification, transparent pricing, and service guarantees.
  • Used User Persona, STP Analysis, and TAM, SAM, SOM to frame the opportunity.
UI/UX DesignUser PersonaSTP AnalysisTAM · SAM · SOM

WEB DEVELOPMENT · HTML, CSS & JAVASCRIPT

Little Lemon

Developed a restaurant website designed to provide customers with easy access to restaurant information, menu details, location, and table-booking navigation.

Website development process

  • HTML — Structure: built the website framework, including navigation, menu, location, and booking sections.
  • CSS — Design: arranged colors, typography, sizing, layout, spacing, and visual presentation.
  • JavaScript — Interactivity: added interactive functions so the website responds to user actions.
