# Shella Mutiara Putri — Personal Portfolio Website

A multi-page, responsive personal portfolio built with HTML, CSS, and vanilla JavaScript. The visual direction is Minimalist Editorial: warm cream backgrounds, serif display typography, muted terracotta accents, and generous spacing.

## Pages
- `index.html` — Home
- `about.html` — About, education, strengths, tools, and interests
- `experience.html` — Internship experience
- `organization.html` — Organizational experience
- `projects.html` — Academic projects
- `certifications.html` — Certificates
- `contact.html` — Contact links

## Run locally
1. Extract this folder.
2. Open the `shella-portfolio` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code extension **Live Server** and click **Go Live**.

## Publish with GitHub Pages
1. Create a **public** GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload all files and folders from this project (keep `index.html` in the repository root).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. Wait for deployment. Your website will be available at `https://YOUR-USERNAME.github.io/`.

## Before publishing
- Review your phone number, email, and social profile links on `contact.html`.
- The original portfolio PDF is included in `assets/docs/` as a downloadable reference.
- The Little Lemon live URL in the source PDF was not fully legible, so it has intentionally not been made clickable. Add the verified URL to `projects.html` when you confirm it.
- Replace the certificate preview with individual high-resolution certificate scans if you have them.
- If you want to use a different profile photo, replace `assets/images/shella-profile.jpg` while keeping the same filename.

## Notes
The site uses Google Fonts (DM Sans and Playfair Display), so typography falls back to system fonts when offline. No framework or build step is required.
